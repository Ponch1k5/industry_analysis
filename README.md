# Анализ строительных предприятий России

Учебный проект на Python: финансовые результаты малых и средних строительных компаний, динамика чистой прибыли и география регистрации. **Цель — оценить перспективность строительного направления на основании полученных результатов.**

## Данные и методика

- Источники: Единый реестр субъектов МСП (срез на 15.04.2024), открытая бухгалтерская отчётность ФНС.
- Отбор: 8 927 юридических лиц с основным ОКВЭД **41.20** (малые и средние предприятия, без микроорганизаций).
- Рабочая выборка: первые 500 строк реестра и ещё 500 случайно выбранных из остальных.
- Отчётность: 2021–2025 гг., 975 организаций с хотя бы одной доступной финансовой записью.
- Сопоставление чистой прибыли: 2023 и 2025 гг.; при расчёте процентного изменения используется положительная база 2023 года, переходы между прибылью и убытком выделены отдельно.
- **EBIT = прибыль до налогообложения + проценты к уплате** (строки 2300 и 2330), без амортизации, согласно условию задания.
- Финансовые значения в CSV — **тысячи рублей**. В выводах совокупные суммы показаны в млрд ₽, на карте выручка — в млн ₽.

## Как запустить

Рекомендуется Python 3.11–3.13.

```bash
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
python -m pip install -r requirements.txt
cd code
jupyter notebook Analysis_code.ipynb
```

В Jupyter: **Kernel → Restart & Run All**. Для анализа **не нужны** запросы к API ФНС или Nominatim — всё берётся из включённых CSV. Скрипт создаёт интерактивную HTML-карту в `outputs/top500_registration_map.html` (на уровень выше папки `code`). Для просмотра подложки OpenStreetMap в браузере необходим интернет.

## Основные результаты (2023–2025)

- **778** компаний имеют сопоставимые показатели выручки и чистой прибыли за оба года.
- Совокупная выручка выросла **на 7,5%** (307,9 → 330,8 млрд ₽), а чистая прибыль сократилась **на 33,0%** (17,4 → 11,7 млрд ₽).
- Рентабельность по чистой прибыли снизилась с **5,65% до 3,53%**.
- Среди **808** компаний с сопоставимой чистой прибылью **123** перешли из прибыли в убыток и **63** — из убытка в прибыль.
- Карта показывает организации из **топ-500 по выручке внутри рабочей выборки**, а не по всей России. Координаты приблизительны и привязаны к городу/региону регистрации. Из 500 компаний на карте показываются 438; остальные 62 не имеют надёжно подтверждённых координат. Один ошибочно определённый населённый пункт исключён из визуализации при проверке кэша.

**Вывод:** результаты позволяют считать направление умеренно перспективным, но демонстрируют заметное снижение прибыльности и финансовые риски исследуемых компаний.
